Etsy SEO trên Codex

Cài skill etsy-seo vào Codex trên máy Windows hoặc Mac. Cài xong, bạn chỉ cần kéo ảnh design vào là nhận được Title, 13 Tags và Description chuẩn SEO Etsy. Làm lần đầu mất khoảng 15 phút.

Title ≤140 ký tự 13 tags × ≤20 ký tự Description: 160 ký tự đầu Long-tail chính 5–6 từ

Chuẩn bị trước

  • Tài khoản ChatGPT Plus (hoặc Team / Pro) đang hoạt động.
  • File Etsy-SEO-Codex.zip do quản lý gửi (qua Drive, Zalo hoặc USB).
  • Trong ChatGPT đã kết nối 2 công cụ ytrends và EverBee. Chưa có thì nhờ quản lý thêm giúp.
  • Máy có Internet và bạn có quyền cài phần mềm.

Các bước cài đặt

  1. 1

    Cài Codex và đăng nhập

    1. Tải app ChatGPT cho Windows (Microsoft Store hoặc chatgpt.com/download)Mac (chatgpt.com/download) rồi cài đặt.
    2. Mở app → đăng nhập tài khoản ChatGPT → chọn mục Codex.
    3. Mở Codex một lần rồi đóng lại. Bước này để Codex tạo thư mục cài đặt riêng của nó trên máy.

    Ai quen dòng lệnh có thể dùng Codex CLI: cài Node.js rồi chạy npm install -g @openai/codex.

  2. 2

    Lấy 2 đường link MCP

    Codex không dùng chung kết nối với ChatGPT, nên cần chép 2 đường link này sang cho Codex.

    1. Trong ChatGPT mở Settings → Apps & Connectors.
    2. Bấm vào ytrends → copy dòng MCP Server URL → dán tạm vào Notepad / Notes.
    3. Làm tương tự với EverBee.
    Link ytrends đúng: https://mcp.trends.ytuong.ai/mcp. Đừng dùng link cũ …/sse, link này đã ngừng chạy (lỗi 410).
  3. 3

    Giải nén gói cài

    Chuột phải vào Etsy-SEO-Codex.zip → Extract All… → Extract. Bạn sẽ có thư mục Etsy-SEO-Codex. Đừng chạy file ngay bên trong zip.

    Bấm đúp Etsy-SEO-Codex.zip trong Downloads. Mac sẽ tự tạo thư mục Etsy-SEO-Codex.

    Trong thư mục có: etsy-seo (skill), install-codex.bat / .ps1 (Windows), install-codex.sh (Mac) và tài liệu này.

  4. 4

    Chạy file cài đặt

    1. Mở thư mục Etsy-SEO-Codex → bấm đúp install-codex.bat.
    2. Nếu hiện màn hình xanh “Windows protected your PC”: bấm More info → Run anyway.
    3. Cửa sổ đen hỏi URL MCP ytrends: dán link ở bước 2 (chuột phải để dán) → Enter. Làm tương tự với EverBee.
    4. Thấy dòng HOAN TAT! → bấm Enter để đóng.
    1. Mở Terminal (nhấn Cmd + Space, gõ “Terminal”, Enter).
    2. Dán lệnh dưới đây rồi Enter:
    Terminal
    cd ~/Downloads/Etsy-SEO-Codex && bash install-codex.sh
    1. Khi được hỏi URL MCP ytrends: dán link (Cmd + V) → Enter. Làm tương tự với EverBee.
    2. Thấy dòng HOAN TAT! là xong.
    Chưa có link MCP? Cứ bấm Enter để bỏ qua. Lấy được link thì chạy lại file cài, skill và cấu hình cũ không bị mất.
  5. 5

    Mở lại Codex và kiểm tra

    1. Thoát hẳn app ChatGPT/Codex (cả biểu tượng dưới khay đồng hồ) (Cmd + Q) rồi mở lại.
    2. Trong ô chat của Codex gõ /skills → phải thấy Etsy SEO POD (etsy-seo).
    3. Gõ /mcp → phải thấy ytrends và everbee. Lần đầu có thể hiện cửa sổ đăng nhập, bạn tự đăng nhập tài khoản của mình.
  6. 6

    Chạy thử lần đầu

    Kéo 1 ảnh design vào ô chat Codex rồi gõ:

    Codex
    $etsy-seo viết SEO Etsy cho design này, product type: t-shirt

    Codex sẽ tự chạy 4 bước: đọc design → tra keyword bằng ytrends + EverBee → lọc tag → viết listing. Cuối cùng bạn nhận được một khối để copy thẳng sang Etsy, ví dụ:

    Long-tail chính · 5 từretro cowgirl mama western shirt
    Title · 125/140Cowgirl Mama Western Shirt, Retro Country Mom Tee, Wildflower Sunset Boho Tshirt, Mothers Day Cowgirl Gift, Rural Mom Apparel
    13 Tags · mỗi tag ≤20
    cowgirl mom shirt17western mama tee16wildflower mom tee18mothers day cowgirl19rural mom apparel17boho mama shirt15sunset cowgirl tee18country mom gift16…

    Đây là ví dụ minh hoạ. Kết quả thật phụ thuộc design và số liệu keyword hôm đó. Report đầy đủ được lưu tại C:\Users\<tên-bạn>\Etsy-SEO\reports\~/Etsy-SEO/reports/.

Dùng hằng ngày

Luôn bắt đầu tin nhắn bằng $etsy-seo và kèm ảnh design. Vài câu lệnh mẫu:

$etsy-seo viết SEO cho design này, product type: sweatshirt
$etsy-seo chỉ cần 13 tags cho design này
$etsy-seo viết SEO cho design này, niche: bird watching, gift cho dad

Trước khi dán lên Etsy, tự soát 4 điểm

  • Title bắt đầu bằng đúng long-tail chính.
  • Đủ 13 tag, không tag nào bị Etsy báo quá dài.
  • Không có tên thương hiệu, nhân vật hay đội thể thao (Disney, NFL, Comfort Colors…). Skill sẽ cảnh báo 🔴 nếu design có rủi ro.
  • Bảng keyword có số thật. Nếu toàn ghi no data thì MCP chưa kết nối, xem mục bên dưới.

Cập nhật hoặc gỡ skill

Cập nhật: nhận gói zip mới → giải nén → chạy lại file cài. Bản cũ được chuyển sang thư mục .agents\skills-backup, không bị xoá.

Gỡ: xoá thư mục C:\Users\<tên-bạn>\.agents\skills\etsy-seo~/.agents/skills/etsy-seo rồi mở lại Codex.

Thư mục bắt đầu bằng dấu chấm bị ẩn. Trên Windows bật View → Show → Hidden items. Trên Mac nhấn Cmd + Shift + . trong Finder.
